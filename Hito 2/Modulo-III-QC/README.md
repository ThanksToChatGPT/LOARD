# Módulo III · QC de usabilidad y accesibilidad

Artefactos de este módulo:

- **Reporte de validación RITE:** pruebas con al menos 2 usuarios reales (perfil, tareas, resultados, iteraciones).
- **Tabla de evidencia:** problema detectado → cambio aplicado en el prototipo, con antes y después.
- **Auditoría de accesibilidad (WCAG):** contraste de color, tamaños de fuente y navegación por teclado.
